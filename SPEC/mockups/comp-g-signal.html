What this unlocks. A status today is a name, a colour and a sort order, so nothing in the product can tell "In Review" from "Complete". Counts as gives every status one of four meanings — Open, Waiting (external), Closed–succeeded, Closed–declined — which is what lets Home say "14 open", lets Complete drop out of default views, and gives the Declined path somewhere to land. Flag after is per-status on purpose: five days in review is late, five days in progress is normal.

Migration to decide before building. Existing organizations have statuses with no meaning recorded. Defaulting every status to "Open" is safe but leaves Complete counting as open until an admin fixes it; inferring from the name works for the seeded set and not for a customer who called theirs "Shipped". The comp assumes default everything to Open, then prompt the Org Admin once with this screen — worth confirming.

Saved views (#5). A view stores the filter set, the sort and the chosen columns — nothing about the results themselves, so it stays correct as ideas move. The pin glyph marks a view an Org Admin has pinned for everyone; unpinned ones are personal. The counts are the point: a pinned "Awaiting review 4" on every member's screen is a standing prompt, which a filter you have to re-type never is.

Ageing (#1) in the list. "9d · stalled" is computed from the status's own Flag after, not from a global rule, and the word stalled is always present next to the colour — the badge never relies on amber-vs-red alone.

Why a grid and not a score (#2). A single computed number (RICE, ICE) hides the disagreement that actually matters — two people can agree on a 7 for different reasons. Nine named cells keep both axes visible and make the argument explicit: "Do first" and "Reconsider" are the only two cells that carry a recommendation, and the rest are just counts. Dragging a card between cells edits the underlying Impact and Effort fields.

Dependency worth stating. This screen is only honest if "open" is real — otherwise six Complete ideas sit in the grid forever. That is the argument for building status semantics (#1) before this, not alongside it.
