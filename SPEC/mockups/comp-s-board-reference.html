What this does
Cards in Implementation can have tasks. Tasks are cards on the Implementation board, which has its own statuses (Pending → In Progress → Review → Complete) and optional sprints. When every task reaches that board's final status, the parent card is offered a move to Completed.
Effort must be set before an idea can enter a reference lane.
