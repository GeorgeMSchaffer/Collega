New / Pending, In Review, In Progress, Client Review, and Complete are the 5 canonical default statuses, provisioned automatically for every new organization (per SPEC/20-feature-boards-and-statuses.md). "Won't Do" here is an example custom status this organization added and later retired — orgs can add, rename, and retire statuses beyond the defaults. An organization must always keep at least one active status. When only one remains, its Delete action is disabled with an explanatory tooltip — see the "Last-status guard" tab. Deleting is always a soft delete (Retire): existing board and idea references stay valid, and a status currently used as a swimlane on an active board can't be deleted until that reference is removed.
