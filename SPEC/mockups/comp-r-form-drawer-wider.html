Notes for the reviewer

  1. Drawer width. This comp compares 520px (the widest the form drawer gets today: --drawer is clamp(380px, 28vw, 520px)) with half the screen width (width: 50vw). Originally 520px, the widest the existing list-and-detail drawer gets, so the form borrows its chrome (scrim, header, close, pinned footer). Full width at 390px. The list stays visible behind the scrim, so the new row is seen in place after save.
  2. Where Effort sits. Directly under Title, in a short Delivery group, not at the foot of the long idea form. It is the one required field besides Title, so required fields sit together and an error never hides below the fold. Alternative: end of the form, next to the Add button.
  3. One scroll or sectioned. One scrolling body with two headed groups (Delivery, Idea details) and a pinned footer. Not tabs or steps: the form is long but linear and nothing has to be reached out of order.
  4. Effort control. Three radio cards with the app's effort bar plus the word and a rough size hint, so colour never carries the meaning. Native radios: arrow keys and one tab stop. The size hints are placeholder copy, to be confirmed.
  5. Where the new row lands. The list is ordered by votes, so a new issue (0 votes) lands at the bottom, highlighted and scrolled into view, with the toast. Picking a sprint other than Backlog means no row appears here; the toast names the sprint instead ("Issue added to Sprint 14").
  6. Read Only. The button stays visible but disabled (aria-disabled, so it can still take focus and be read) with the reason as visible text beside it, linked by aria-describedby. Row Edit actions are removed rather than disabled.
  7. Edit mode. Same drawer and fields minus the Delivery group (Effort, Sprint), and no Board or Status. Footer button reads Save changes. Effort remains editable where it is today.
  8. Errors. Messages sit directly under the failing control, tied to it with aria-describedby and aria-invalid; a one-line summary in the footer announces the count. Focus moves to the first invalid field.
