Four ways to see every sprint: upcoming, ongoing, completed

Today a board's Sprints tab lists that board's sprints with no order or grouping, and the Sprint board shows only the one active sprint. Nothing shows what is coming. These four comps keep the data rules (a sprint belongs to one board; states are Planned, Active, Completed) and differ in where the view lives and how it is grouped. Planned is worded Upcoming and Active Ongoing COPY PROPOSED.

Archived: there is no archived sprint. Completed is the end state, so every comp shows Completed where you said archived. A real Archive (hide old sprints) would be a new decision.

My read: B as the page everyone lands on, with C and D as optional view toggles later, and A as a cheap first step because it needs no new page. Whichever is chosen, the Sprint board should gain an "All sprints" link and a switcher so a past or upcoming sprint opens there too.
