Custom fields & fieldsets

Make the form fit your work, not the other way around.

Admins create fields once, group them into fieldsets, and choose what each idea type asks for. Pick a type to see the form it makes.

1 · Fields: seven types

2 · Fieldsets: reusable groups

Fieldsets are shared, not copied. Edit one and every idea type that uses it changes too.

3 · Idea types: choose what each one asks

Ask only what matters

A risk needs a risk level. A process improvement needs a business case. Each idea type asks only for its own.

Required where it matters

Required is set per idea type, so a field can be mandatory for one and optional for another.

Searchable and portable

Filter lists by custom values and carry them through CSV. Delete a field and its values are kept, just hidden.

Reference workflows

Know exactly where implementation stands.

In most tools, an approved initiative sits in an “Implementation” column for months, and all you know is that it started. In Collega, a status can point to a work board, so the detail is one click away and the progress rolls back up.
