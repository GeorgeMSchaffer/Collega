F–H / Narrative audit alternatives

The original and all earlier concepts remain unchanged. The three additions keep the same positioning, capability and beta copy, exact 02C geometry, native form fields and local Privacy note. They change composition, evidence order and framing, not product claims.

Contract: cross-functional teams need to understand the ideas-to-delivery approach and request beta access. The category default is a centered slogan, tiny dashboard and repeated cards. Its predictable opposite is oversized editorial type with little product proof. F–H instead show the real rationale, board status or sprint goal on the first screen. One amber interaction accent; 0/6/8px radius scale; no emoji or gradients. Screenshot and semantic error colors are preserved exceptions.

Local state demo: F–H briefly show “Checking locally…” with duplicate activation blocked, then honest nothing-sent feedback and a preserved draft. This is not network loading or provider acceptance. No endpoint, credentials, account, email, subscription or persistence is integrated. Without JavaScript, submit remains disabled.

Reference limits: existing Graphite globals, actual components and inspected local captures are the primary evidence. Public Linear features copy was a related lifecycle reference only, not an inspected visual target or a source of WorkSprint claims. Paid UIZZE retrieval was unavailable. Image-first generation was skipped because image generation and screenshot upload were not authorized. Captures and the final validation receipt live in the session artifact directory, not the repository.

Design-hook scope: 0px editorial rules, 6px controls and 8px evidence/form frames are deliberate comp values derived from the current app. They do not authorize changing DESIGN.md, design-system tokens or hook settings.

Earlier A–E design contract and exploration boundaries

Audience: cross-functional teams managing ideas through delivery. Primary task: understand the approach and request beta access. Journey: hero → real app preview → workflow and capabilities → beta FAQ → form → local validation feedback.

A–C retain their exploratory palettes. D–E use Graphite, the app’s IBM Plex Sans / JetBrains Mono stacks, 600 headings, .9rem–2.053rem type scale and 6px control / 8px card geometry. Public controls use a 44px floor. No remote fonts, invented claims, live intake, production changes or approval are implied.
