Notes

What this does
With the switch on, one task is created for every card that enters Implementation, and the card waits on it. With it off, people add tasks by hand, as many as they need, and the card still waits on whatever exists.
Removing the board reference turns the switch off. If you try to save the switch on with no reference, the server answers 422 autoCreateTaskRequiresReference; this form never lets you get there.
