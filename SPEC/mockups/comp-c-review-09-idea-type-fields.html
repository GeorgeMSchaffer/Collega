Last-type guard. When an org is down to one active idea type, its Archive action is disabled with a tooltip — "Cannot archive the last remaining idea type; every idea must have one." Archiving a type in use is a soft delete: existing ideas keep the badge and still resolve their fields; the type just leaves the create picker.

Migration. On ship, existing types (e.g. Defect) are mapped to all current org fields, so nothing changes for existing ideas until an admin curates a type's field list.

Direct type→field mapping (the chosen model). Fields are attached straight to the type — no separate "field set" concept. The org's field pool stays shared (a field like Impacted Team can sit on several types and still reports as one field); each type just selects an ordered subset and sets required per field on the type↔field link. Removing a field here hides it for new ideas; existing values are preserved (shown archived on detail), never dropped.
