Direction B — Live Draft

One surface instead of two. The conversation is on the left; the idea takes shape on the right as the assistant proposes values. There is no handoff — Review & create opens the normal create modal already filled, or commits straight from here. The bet: seeing classification land while you talk is what teaches the user what this thing actually does.

What it settles

  • Suggestion indicator: same teal vocabulary as Direction A, but carried by the draft card itself — a teal dot, tinted card, 3px left border. No chip is needed because the whole panel is the suggestion surface.
  • Suggestion vs. user edit: editing a field drops the teal marker permanently and later turns won't overwrite it. Direction A can't express this — by the time you see the form the conversation is over.
  • Out-of-scope: the draft panel visibly does not change. That is the strongest possible statement of rule 8 — the off-topic turn touched nothing.
  • Pending: the draft dims but stays readable; it never blanks. Cancellable per rule 33.
  • Failed: the draft holds everything already agreed, and Review & create stays enabled — rule 32's "never blocked" made visible.
  • Scope statement: a section inside the existing Organization drawer (deliberately the opposite choice from Direction A, so reviewing both settles the placement question).

What it costs

  • A new surface: a 1080×660 sheet. CreateModalShell is 720px and doesn't stretch to a two-pane layout, so this is genuinely new chrome to build, style, and make accessible.
  • Narrow viewports are unsolved. Below 900px this comp hides the draft panel entirely — which means either a tab switcher or a fallback to Direction A's flow on mobile. Comp C's mobile pass is still open (`client/CLAUDE.md` → "Still undesigned"), so this direction inherits that debt.
  • More state to manage: per-field "suggested vs. user-edited" tracking that Direction A gets for free by only rendering once.
The real question

Is the assistant's classification work worth showing live? If users mostly accept what it proposes, Direction A is strictly cheaper. If they'll want to correct the Idea Type mid-conversation — which is exactly when correcting it is cheapest — Direction B pays for its extra surface.

Hybrid worth considering

Direction A's flow with a slim read-only draft strip above the composer: shows the three classification values as pills, no editing, no second pane. Most of B's feedback at close to A's cost. Say the word and I'll draw it as 11C.
